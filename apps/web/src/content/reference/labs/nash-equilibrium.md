---
term: 'Nash equilibrium'
game: 'labs'
kind: 'concept'
level: 'intermediate'
summary: 'A set of choices where no player can do better by changing only their own.'
related: ['labs/prisoners-dilemma', 'labs/mixed-strategy', 'labs/zero-sum-game']
---

Each player's choice is a best answer to the others'. An equilibrium need not be good for anyone: in the Prisoner's Dilemma, both betraying is the equilibrium, and both would prefer mutual cooperation.
