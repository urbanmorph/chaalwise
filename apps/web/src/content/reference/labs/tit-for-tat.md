It is simple, and it famously did well in tournaments of the repeated Prisoner's Dilemma. It is nice (it never betrays first), hits back after a betrayal, forgives, and is easy for others to understand. A slightly forgiving version does even better when mistakes happen.

Tit for tat never beats the player it faces: at best it ties. It does best overall because it gets others to cooperate. It is not unbeatable either. When moves can be misread, other simple rules can do better.
